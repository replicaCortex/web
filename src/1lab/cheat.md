# Ответы на контрольные вопросы

1.  **Архитектура:** Модель взаимодействия, где клиент запрашивает ресурсы, а сервер их предоставляет. Компоненты: Клиент (браузер), Сервер (код), Сеть (протоколы).
2.  **Методы HTTP:** `GET` (получение данных), `POST` (создание), `PUT` (обновление), `DELETE` (удаление).
3.  **Статус-коды:** `200 OK` (успех), `404 Not Found` (не найдено), `500 Error` (ошибка сервера).
4.  **HTTP vs HTTPS:** HTTPS — это HTTP с шифрованием (SSL/TLS).
5.  **Заголовки:** Метаданные запроса (тип контента, авторизация).
6.  **Контейнеризация:** Упаковка кода и окружения в один образ для гарантии работы "везде".
7.  **Образ vs Контейнер:** Образ — это "чертеж/диск", контейнер — это запущенный экземпляр этого образа.
8.  **Типы данных:** JSON (чаще всего), XML, Plain Text, HTML.
9.  **Маршрутизация:** Сопоставление пути в URL (например, `/info`) с конкретной функцией в коде.
